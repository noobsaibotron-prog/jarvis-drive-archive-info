PERSONAL DATA ARCHIVE

JARVIS Drive Archive

A personal tool for backing up selected JARVIS memory files to the owner's Google Drive.

The desktop tool creates an archive of selected Markdown memory files. After the owner authorizes Google Drive access, it can upload, verify and recover those archives. It can rebuild a local catalog from the archive folder. Recovery is performed into a separate directory.

Google Drive access is requested using the drive.file scope, for files created or specifically made available to the app. Google displays the requested access before the owner grants permission.

This page describes the archive component for personal use. The owner can schedule verified backups on their Mac. Recovery directly from a new device has not yet been fully tested.
